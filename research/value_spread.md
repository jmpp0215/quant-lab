## 46. 가치 스프레드가 클 때 이후 PBR 전략 성과 — 사전 등록 (2026-10-24, 결과 전 기록, 연구 전용)

근거: 가치 스프레드가 크면 이후 가치주 초과수익이 크다(Asness 외, "value spread"). 시장 지도 1단계에서 스프레드 시계열은 봤지만
PBR 전략의 이후 성과와는 맞춰 보지 않았음.

- 날짜: §36·§41 리밸런싱 격자(20거래일마다, 오프셋 0·10), 2005-09 ~ 2026-10. 가치 스프레드 = 시장 중간 PBR ÷ PBR 하위 50 중간 PBR
  (그날 스냅샷), 그 시점까지 과거 5년(최소 2년) 안의 백분위.
- 결과: 이후 12번 리밸런싱(약 240거래일) 동안 PBR Top 50 누적 수익률 − 적격 전 종목 동일가중 누적 수익률(§36 규칙, 윈저화 1/99, 상폐 0%).
- **판정**: 백분위 상위 1/3 날짜의 평균 초과수익 − 하위 1/3 날짜 평균 > 0, 연도 단위 블록 부트스트랩 10,000번에서 차이 ≤ 0 비율 ≤ 5%,
  오프셋 0·10 모두. 전반·후반 같은 방향.
- 보고만: 3분위별 평균, 상폐 −100%, 60일(3번 리밸런싱) 결과.
- 한계: 1년 결과가 서로 크게 겹쳐(매 20일 시작) 유효 표본이 작음 — 연도 블록 부트스트랩으로 일부 반영.

**결과 (2026-10-24)** — `scratch/market_map/stage2.py s46`(출력 `s45_s46_out.txt`). 2007-10 ~ 2025-10 시작 날짜 오프셋별 약 224개. 벗어난 점 없음.

사용자 결정 전에는 적용하지 않음. 지금(2026-10) 스프레드 3.25.

**재실행 (2026-11-22, 신주 발행 정정)**: **통과 유지.** 스프레드 상위 1/3 대 하위 1/3의 1년 PBR 초과수익 차이 오프셋 0 +6.69 → +6.62%p(p 0.037 → 0.038), 오프셋 1 +6.93 → +6.50%p(p 0.034 → **0.049**, 기준 0.05에 가까움). 두 절반 모두 양수 유지. (일괄 재실행 표는 §72 뒤 "신주 발행 정정 일괄 재실행")

## 48. 가치 스프레드로 새 입금 나누기(ISA 모멘텀 vs 토스 PBR) — 사전 등록 (2026-10-24, 결과 전 기록, 연구 전용)

§46(스프레드가 크면 이후 1년 PBR Top 50 초과수익 +7%p)을 실제로 쓸 수 있는 가장 위험 작은 형태: 매도 없이 **새 입금만** 스프레드에 따라 두
계좌로 나눈다. **§46과 같은 데이터라 새로운 증거가 아님** — 이 시험은 "현실적인 입금 방식으로 옮겼을 때 이득이 남는 크기인가"를 본다.
진짜 확인은 이후 실전 기록뿐. 결과와 무관하게 실전 변경은 사용자 결정.

**데이터**: 모멘텀 = `scratch/momproxy/out/loo_F.json`의 기본(8종목, 비용 포함, 지수 대체 체인) 계좌 가치 2008-04 ~ 2025-12. PBR = §36·§41 규칙
PBR Top 50(20거래일 리밸런싱, 오프셋 0·10, 비용 반영, 윈저화 1/99, 상폐 0%) 2005-09 ~ 2026-10. 스프레드 백분위 = §46과 같음. 두 계좌 가치는
월말 값(그 날 이전 마지막 값)으로 맞춤.

**사전 고정**:
- 2008-05부터 2025-12까지 매월 첫 날 1단위 입금(월말 값 기준). 기존 보유분은 절대 팔지 않음.
- 목표 PBR 비중 t: **고정 규칙** t = 40%. **스프레드 규칙** t = 50%(백분위 ≥ 66.7) / 30%(≤ 33.3) / 40%(그 사이).
- 입금 배분: 입금 후 PBR 비중이 t에 가장 가깝도록, PBR에 넣을 금액 = min(max(t × (총액 + 입금) − PBR 가치, 0), 입금), 나머지는 모멘텀.
- **판정**: 오프셋 0·10 모두에서 스프레드 규칙이 고정 규칙보다 ① 최종 자산이 크고 ② 월간 시간가중 수익률의 Sharpe가 높음. 그리고
  전반(2008-05 ~ 2016-12)·후반(2017-01 ~ 2025-12)을 각각 새로 시작한 시뮬레이션에서도 ① 성립.
- 보고만: 최종 자산 차이(%), CAGR, MDD, 평균 PBR 비중, 규칙별 PBR 비중 분포, 입금 전부 한쪽(100% 모멘텀 / 100% PBR) 결과.
- **한계**: 모멘텀은 대체 데이터 백테스트, PBR은 비수정 종가·윈저화 수준(절대 수준은 과대평가 가능), 세금(ISA vs 일반) 미반영, 입금 한도
  미반영. 두 전략의 상대 성과가 결과를 좌우하므로 수준 차이가 아니라 두 규칙 간 차이만 본다.

**결과 (2026-10-24)** — `scratch/market_map/deposit_rule.py`(출력 `deposit_rule_out.txt`). 2008-05 ~ 2025-12 월 212회 입금. 벗어난 점 없음.

+1~4%지만 전체 기간에서는 경로에 따라 부호가 바뀜. §46의 "1년 초과수익 +7%p"는 새 입금만 나누는 방식으로 옮기면 거의 남지 않음(입금이

같은 결론. 스프레드 정보를 쓰려면 입금 배분보다 강한 수단(기존 보유분 재조정)이 필요하나 그만큼 비용·세금·위험이 큼 — 현 시점 권고는
"고정 비율 유지".

## 57. 가치 스프레드 효과의 통계적 강건성(§46 재검증) — 사전 등록 (2026-11-17, 결과 전 기록, 연구 전용)

**배경**: §46은 "스프레드 상위 1/3 vs 하위 1/3 이후 1년 초과수익 차이 +7%p, 연도 블록 부트스트랩 p≈0.035"로 통과했다. 이 절은 같은
2005-09~2026-10 데이터를 다시 보는 **재분석이라 새 증거가 아니다**. 결과는 "§46이 검정 방식·구간 선택에 얼마나 민감한가"만 말한다.
새 표본 밖 증거는 아래 전향 기록(§57-F)뿐이다. §58~§60을 포함한 전체 설계는 2026-11-17 사용자 승인안을 따른다(§58·§59는 이 절 결과 후
따로 사전 등록, §60은 독립). 결과는 실전을 바꾸지 않는다.

**데이터·변수 (§46 그대로, 바꾸지 않음)**: `scratch/market_map/stage2.py`의 `grid_snaps()` 10거래일 KOSPI 스냅샷(2005-09 ~ 2026-10).
적격 = BPS>0·종가>0·거래량>0. 스프레드 = 적격 중간 PBR ÷ PBR 하위 50 중간 PBR, 백분위 x = 과거 125칸(최소 52칸) 안 순위.
r_top·r_ew = 날짜 d에 만든 Top 50·적격 동일가중의 d → 2칸 뒤(20거래일) 수익률(`step`, 분할 보정, 상폐 0%, 단면 윈저화 1/99).
y = 시작일 d부터 같은 오프셋의 20일 수익률 12개를 이어 곱한 Top 50 누적 − 동일가중 누적(비용 미반영, §46과 같음).
BPS 이월은 스냅샷 전체가 빈 날만(2008-08-14~11-25, 최대 120거래일). 우선주 포함(주), 제외(종목코드 끝자리 ≠ 0)는 보고만.

**주 가설**: y = a + b·x + e에서 H0: b = 0, H1: b > 0(단측).
- **표본**: 오프셋 0·10의 시작일을 합쳐 날짜순으로 놓은 10거래일 간격 표본(약 450개). 인접 y끼리 약 24~25개 관측이 겹친다.
- **NW**: t = b̂ / se_NW, Bartlett 커널, **주 지연 25**, 주 p = 정규근사 단측 P(Z ≥ t). 지연 12·30, 그리고 t분포(자유도 = 표본의
  달력 연도 수 − 2) 단측 p는 민감도로 보고만 한다.
- **귀무 제한 잔차 블록 부트스트랩**: 귀무 모형 y = a + e(â = ȳ), e⁰ = y − ȳ. e⁰를 원형 이동 블록으로 다시 뽑아 y* = ȳ + e⁰*를 만들고
  x는 원래 순서로 고정. y*를 x에 회귀해 t* = b̂*/se_NW*(지연 25). 블록 25관측(1년)·50관측(2년), 각 B = 10,000, 시드 57.
  단측 p = (1 + #{t* ≥ t_obs}) / (B + 1). §46의 달력 연도 블록 방식은 연속성 참고로만 보고.
- **위상 안정성(유의성 기준 아님)**: 합친 표본에서 j, j+25, j+50, …번째(j = 0..24) 시작일만 쓴 겹치지 않는 표본으로 b를 25번 구한다.
  25개 위상은 같은 데이터를 공유해 서로 독립이 아니며, "b > 0이 17/25 이상"은 시작일을 바꿔도 방향이 유지되는지만 본다.
- **전반·후반**: 시작일 2007~2015 / 2016~2025로 나눠 각각 b.

**판정 (모두 사전 고정, "같은 데이터의 재분석" 표시를 붙임)**:
- **통과**: NW(25) p ≤ 0.05, 1년·2년 부트스트랩 p 모두 ≤ 0.05, 전반·후반 b 모두 > 0, 위상 b > 0이 17/25 이상 — 모두 충족.
- **잠정 통과**: b > 0이고 세 p(NW 25, 1년, 2년) 중 하나 이상 ≤ 0.05이지만 통과 조건을 다 채우지 못함.
- **기각**: b ≤ 0, 또는 세 p 모두 > 0.10.
- **추가 검증 필요**: 그 밖.

**보고만(판정에 안 씀)**: 상·하위 구간 20/25/33/40% × 기간 3/6/12/24개월 16칸의 상·하위 평균 차이와 NW p(지연 = 그 기간의 겹치는
칸 수), 같은 부호 칸 수, Holm 보정 p — 가장 좋은 칸을 고르지 않음. 상폐 −100% 가정, 우선주 제외 버전, 오프셋별(20일 간격) 결과.

**실행 전 점검(결과와 무관, 출력 맨 앞)**: ① §46 원본 재현(오프셋 0/10 차이 +6.69 / +6.93%p, p 0.037 / 0.034). ② NW 구현: 지연 0 =
HC0, 손계산 예제 일치. ③ 부트스트랩 크기 점검: 같은 x와 b = 0인 모의 y(실제 잔차를 블록으로 섞어 만듦) 200회에서 1년 블록 기각률(p ≤ 0.05)
보고 — 5%에서 크게 벗어나면 결과 해석에 적음. ④ 수동 점검: 스프레드 상위 10개 날짜와 무작위 10개 날짜(시드 57)의 하위 50 구성 —
우선주 비율, BPS 이월 여부, PBR < 0.1 종목 수, 분할 보정 건수.

**전향 기록 §57-F (유일한 새 증거)**: 이 절 커밋 뒤 첫 10거래일 격자 날짜부터 스프레드, 백분위, 하위 50 명단을 기록하고 12개월 뒤
y를 채운다. 겹치지 않는 y가 3개 이상(빨라야 2029-11) 쌓이면 같은 주 검정으로 판정한다. 그전에는 결과를 보지 않는다(§50 방식).
기록 코드는 별도 작업.

**사전 예상(결과 전에 적음)**: b > 0은 유지되지만 겹침 보정 후 유의성이 약해져 **잠정 통과**.

**한계(사전 명시)**: ① 같은 데이터 재분석(새 증거 아님). ② 비수정 종가·배당 미포함·관리종목 필터 없음(§36과 같음). ③ 유효 표본은
약 18~19년치. ④ 16칸 보고는 다중 비교라 판정에 쓰지 않는다.

**결과 (2026-11-17)** — `scratch/value_spread/s57.py`(통계 함수 `common.py`), 출력 `scratch/value_spread/s57_out.txt`. 사전 등록에서

## 58. 가치 스프레드 확대의 경제적 원인 — 사전 등록 (2026-11-17, 결과 전 기록, 연구 전용)

**질문**: 같은 스프레드 수준이라도 "왜 벌어졌는가"에 따라 이후 PBR Top 50 초과수익이 다른가. §57과 같은 데이터(새 증거 아님)이고
결과는 실전을 바꾸지 않는다. 데이터·y·x·스냅샷 규칙은 §57과 같음(`grid_snaps`, 10거래일, 오프셋 합친 표본).
EPS는 같은 날 KRX `fund_*.csv`의 EPS, **EPS 0은 결측**. ROE = EPS/BPS.

**대상 날짜 t**: x ≥ 66.7이고 실제 Δlog S(t−12칸 → t, 약 6개월) > 0이고 y가 있는 날.

**고정 구성 기여도 (t−12 구성 고정)**:
- 그룹: C = t−12의 적격 PBR 하위 50, M = t−12의 적격 전 종목(주), H = t−12의 PBR 상위 20%(보고만).
- 종목 i는 t−12와 t 모두 BPS>0·종가>0이고 12칸 동안 매 칸 가격이 이어지는 종목만 쓴다(탈락 수 보고, 상폐 종목은 제외).
  - ℓ_i = log(PBR_i,t / PBR_i,t−12), p_i = log(1 + 12칸 분할 보정 누적 수익률)(`step` 연쇄), k_i = p_i − ℓ_i(분할 보정 Δlog BPS).
  - ℓ_i와 p_i는 그날 M 전체 분포의 1%/99%로 윈저화(같은 경계를 C·H에도 적용). k_i는 윈저화 후 p_i − ℓ_i로 다시 계산해 항등식 유지.
- 그룹 값 = 동일가중 평균: D_G = mean ℓ_i, P_G = mean p_i, K_G = mean k_i(D_G = P_G − K_G).
- 고정 구성 확대량 W = D_M − D_C. 실제 Δlog S와 W의 상관·평균 차이를 보고.

**기여도 비율 (W > 0일 때만)**: s_M = D_M/W, s_C = (−D_C)/W, s_M + s_C = 1. s_C > 1 = 두 쪽 모두 PBR 하락이지만 싼 쪽이 더 하락,
s_C < 0 = 싼 쪽 PBR이 올랐지만 비싼 쪽이 더 오름.
- 분류: 싼 쪽 주도 s_C ≥ 2/3 / 비싼 쪽 주도 s_M ≥ 2/3 / 양쪽(그 밖) / 분류 불가 W ≤ 0(개수 보고).
- 싼 쪽 내부(−D_C > 0일 때): 가격 하락 몫 = (−P_C)/(−D_C), BPS 증가 몫 = K_C/(−D_C). 가격 하락 몫 ≥ 2/3이면 "가격 주도".
- ROE: C 중 t−12와 t 모두 EPS가 있는 종목의 (ROE_t − ROE_t−12) 중간값 ΔROE. **유지** ≥ −1.0%p, **하락** < −1.0%p(−0.5/−2.0%p는 민감도).

**주 가설**: 같은 x에서 A = "싼 쪽 주도·가격 주도·ROE 유지" 날짜의 y가 Bc = "싼 쪽 주도·ROE 하락" 날짜보다 크다.
- 통계량: A ∪ Bc 날짜에서 y = a + b·x + c·1[A] 회귀의 c.
- 에피소드 = 대상 날짜 중 A ∪ Bc에 속하는 날이 격자상 연속된 묶음. 에피소드 분류 = 그 안 날짜의 다수 분류(동수면 앞 날짜의 분류).
  독립 에피소드 수 = 시간 순으로, 직전에 센 에피소드 끝에서 12개월(250거래일, 25칸) 이상 떨어져 시작하는 에피소드만 센다.
- 귀무 제한 검정: 에피소드 분류 표시를 에피소드 단위로 무작위로 섞어(개수 유지) c*를 다시 계산, B = 10,000, 시드 58.
  단측 p = (1 + #{c* ≥ c_obs}) / (B + 1).
- **판정**: A 또는 Bc의 독립 에피소드 < 4 → **추가 검증 필요**(가능성 높음). 둘 다 ≥ 4이면 c > 0이고 p ≤ 0.05 → 통과, c > 0이고
  p > 0.05 → 잠정 통과, c ≤ 0 → 기각.

**세 설명의 보조 근거 (보고만, 판정 아님)**:
1. 과잉 매도: A 날짜에 만든 Top 50의 이후 12개월 가격 수익과 그 종목들의 이후 ΔROE(이익이 회복되지 않아도 가격이 오르는지).

   종목 비율, 그리고 t에 만든 Top 50의 이후 12개월 실현 변동성·MDD를 분류별로 비교. **ROE 하락만으로는 위험 보상으로 인정하지 않고**,
   위험 지표 상승과 이후 실현 위험 증가가 같이 보여야 그렇게 서술한다.
3. 단순 평균회귀: 모든 분류 가능 대상 날짜에서 y = a + b·x + c₁·1[싼 쪽 주도] + c₂·1[비싼 쪽 주도] (기준 = 양쪽), NW(25) 양측 p가

## 61. §58 재시도 — 연간 ΔROE로 과잉 매도 vs ROE 하락 비교 — 사전 등록 (2026-11-17, 결과 전 기록, 연구 전용)

**배경**: §58은 6개월 ΔROE를 썼는데 KRX EPS·BPS가 1년에 한 번(대부분 5월) 바뀌어 ΔROE가 구조적으로 0이 됐고, 비교 대상(Bc)이 0개였다.
이 절은 **ROE 측정만 바꾸고** 나머지(대상 날짜, 고정 구성 분해, 분류 경계 2/3, 가격 주도, 주 가설, 에피소드·순열 검정, 판정)는 §58과 똑같이
쓴다. 같은 데이터이고 §58 결과(대상 날짜·분류)를 이미 봤으므로 새 증거가 아니다. 실전은 바뀌지 않는다.

**바뀐 변수 하나 — 연간 ΔROE**:
- C(t−12의 하위 50 고정 구성) 종목별 ROE = EPS/BPS(KRX, EPS 0 = 결측). 스냅샷 전체 EPS가 빈 날(2008-08~11)은 직전 EPS를 이어 씀(최대 120거래일,
  BPS와 같은 규칙).
- **시점**: §60 점검(EPS 변경이 공시보다 앞선 비율 11.8%)의 규칙대로 6칸(60거래일) 늦춘 값을 쓴다. ΔROE_i = ROE_i(t−6) − ROE_i(t−31)
  (25칸 = 약 1년 간격이라 연 1회 갱신을 정확히 한 번 포함). 두 시점 모두 EPS·BPS가 있는 종목만, 종목별 변화의 중간값.
- 유지 ≥ −1.0%p, 하락 < −1.0%p(−0.5/−2.0%p는 민감도). §58과 같은 경계.

**주 가설·판정 (§58과 동일)**: 같은 x에서 A = 싼 쪽 주도·가격 주도·ROE 유지의 y가 Bc = 싼 쪽 주도·ROE 하락보다 크다. 통계량 = y ~ x + 1[A]의 계수 c.
A 또는 Bc 독립 에피소드 < 4 → 추가 검증 필요. 둘 다 ≥ 4이면 에피소드 단위 분류 순열(B = 10,000, 시드 61) 단측 p ≤ 0.05 → 통과, c > 0이고
p > 0.05 → 잠정 통과, c ≤ 0 → 기각.

**보고만**: 분류별 ΔROE 분포, A·Bc의 이후 위험 지표(§58과 같은 정의), 6칸 늦춤 없이 계산한 버전.

**사전 예상(결과 전에 적음)**: 싼 쪽 주도 37일이 6개 남짓 묶음(2008~09, 2010, 2011, 2012~13, 2019~20, 2025)에 몰려 있어 둘로 나누면 각 분류의 독립
에피소드가 4개에 못 미칠 가능성이 높다 → **추가 검증 필요**가 가장 유력. 방향은 2008~09·2020 급락 직후 연간 ROE가 크게 떨어졌다면 Bc 쪽 y가
더 클 수도 있다(위험 보상 쪽).

**한계**: §58과 같음 + ① 연간 ΔROE는 스프레드가 벌어진 6개월보다 앞선 회계연도 이익 변화를 담을 수 있다. ② 6칸 늦춤도 미래 정보를 완전히
막지 못한다.
